# markolofsen/assets

Public CDN for README assets — images, hero banners, and badges used across open-source packages.

## Usage

Reference any asset directly via raw GitHub URL:

```
https://raw.githubusercontent.com/markolofsen/assets/main/libs/{project}/{name}.webp
```

Or via jsDelivr CDN (cached, faster):

```
https://cdn.jsdelivr.net/gh/markolofsen/assets@main/libs/{project}/{name}.webp
```

## Structure

```
libs/
  cmdop/        # CMDOP Python & JS SDK packages
  djangocfg/    # DjangoCFG Python & JS packages
  sdkrouter/    # SDKRouter packages
  promo/        # Promo/competitor packages
assets/         # Repository assets (headers, badges)
```
