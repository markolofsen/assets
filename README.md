# markolofsen/assets

Public CDN for README assets — images, hero banners, and badges used across open-source packages.

## Usage

Reference any asset directly via raw GitHub URL:

```
https://raw.githubusercontent.com/markolofsen/assets/main/libs/{slug}.webp
```

Or via jsDelivr CDN (cached, faster):

```
https://cdn.jsdelivr.net/gh/markolofsen/assets@main/libs/{slug}.webp
```

## Structure

```
libs/       # Package hero images (comic strip banners)
assets/     # Repository assets (headers, badges)
```
